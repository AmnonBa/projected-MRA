# Projected MRA Reconstruction Experiments

This repository contains MATLAB code for numerical experiments on the projected multi-reference alignment (projected MRA) model. The code compares several reconstruction methods for recovering a signal up to its intrinsic dihedral ambiguity from noisy projected observations.

## Model

The projected MRA observation model is

```math
y_i = \Pi(R_{\ell_i}\theta) + \xi_i,
```

where:

- `theta` is an unknown real signal of length `p = 2q + 1`;
- `R_ell` is a cyclic shift by `ell`;
- `ell_i` is sampled uniformly from `Z/p`;
- `Pi` is the reflection-symmetric projection defined by

```math
(\Pi v)[j] = v[j] + v[-j], \qquad j = 1,\ldots,q;
```

- `xi_i ~ N(0, sigma^2 I_q)` is additive Gaussian noise.

The recovery goal is to estimate `theta` up to the dihedral orbit generated by cyclic shifts and reflection.

## Compared Methods

The main experiment compares the following reconstruction methods:

1. **Expectation--Maximization (EM)**  
   A likelihood-based benchmark for the projected MRA model.

2. **Direct projected-moment optimization**  
   Nonlinear least-squares optimization over the projected moments `T^(1)`, `T^(2)`, and `T^(3)`.

3. **Direct Fourier-cosine moment optimization**  
   Nonlinear least-squares optimization over the transformed Fourier-cosine moments `M^(2)` and `M^(3)`, together with the first projected moment.

4. **Hard-IRLS phase synchronization**  
   A phase-based method using third-order Fourier-cosine phase relations.

The code records reconstruction error, raw runtime, iteration counts, time per iteration, normalized runtime, and moment-noise diagnostics.

## Requirements

- MATLAB
- Optimization Toolbox, for `lsqnonlin`

The main script checks that `lsqnonlin` is available before running.

## How to Run

From the repository root, run:

```matlab
compare_projected_mra_four_methods_lsqnonlin_runtime_normalized
```

The main script adds the helper folders to the MATLAB path. If you run individual functions manually, make sure the relevant folders are on the MATLAB path.

## Main Parameters

The main experiment script contains the user-facing parameters near the top of the file. Important parameters include:

```matlab
p = 13;                    % Signal length, p = 2q + 1
n = 100000;                % Number of samples
numTrials = 100;           % Number of Monte Carlo trials
sigmaList = logspace(...); % Noise levels
successErrTol = 0.20;      % Success threshold for dihedral-orbit error
```

Method-specific parameters are grouped into structures:

```matlab
irls   % Hard-IRLS settings
opt    % lsqnonlin settings for direct moment optimization
em     % EM settings
```

## Outputs

The script prints summaries for each noise level and final tables for:

- median reconstruction error;
- mean squared error;
- success probability;
- median raw runtime;
- average total iterations;
- median normalized runtime;
- median raw time per iteration.

If `makePlots = true`, the script also generates plots for reconstruction error, MSE, success probability, runtime, iteration count, and moment-noise diagnostics.

If `savePlots = true`, figures are saved to the folder specified by:

```matlab
plotFolder = 'projected_mra_four_method_lsqnonlin_results';
```

## Notes on Runtime Normalization

In addition to raw runtime, the script computes a normalized runtime by multiplying the number of iterations by a reference time-per-iteration. The reference time-per-iteration is estimated from the first few noise levels, controlled by:

```matlab
runtimeCalibNumSigmas = 3;
```

This is intended to separate iteration-count effects from long-run runtime fluctuations.

## Numerical Diagnostics

The script records relative third-moment errors in both projected coordinates and Fourier-cosine coordinates:

```matlab
relT3err
relM3err
```

These diagnostics are useful for observing the finite-sample noise amplification caused by transferring projected moments to Fourier-cosine coordinates via `A^{-1}`.

## Reproducibility

The random seed is fixed at the beginning of the main script:

```matlab
rng(1);
```

Changing this seed will generate different ground-truth signals, shifts, noise realizations, and random initializations.

## Implementation Notes

- The refactoring is intended to preserve the logic of the original monolithic MATLAB script.
- The EM M-step solves a linear least-squares problem in the original signal variable `theta`.
- The direct `T`-moment and `M`-moment methods use `lsqnonlin` with multiple starts.
- The hard-IRLS method is used both as an independent method and as an initialization for the direct moment methods and EM.

## Citation / Manuscript Context

This code accompanies numerical experiments for the projected MRA model studied in the manuscript on projected multi-reference alignment. The main population result shows that, for odd signal length and under generic nondegeneracy conditions, the first three population moments determine the underlying signal up to its dihedral orbit.
